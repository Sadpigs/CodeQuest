# ⚡ CodeQuest — офлайн-академия программирования

## 💻 Версии и установка

### Файлы CodeQuest

| Файл | Для чего |
|---|---|
| **CodeQuest-Desktop-exe.zip** | Настольная версия (Windows / macOS / Linux) — как настоящая программа в своём окне |
| **CodeQuest-Portable-HTML.zip** | То же приложение одним HTML — распаковать и открыть в браузере, работает всегда |
| **CodeQuest-Android.apk** | Приложение для Android — установить как обычный APK |
| **CodeQuest-macOS.zip** | Отдельный архив для Mac (три бинарника + ресурсы) |
| **CodeQuest-PWA-site.zip** | Архив для хостинга в интернете — нужен для установки на iPhone (см. ниже) |
| **CodeQuest-iOS.zip** | Полный Xcode-проект для сборки нативного iOS-приложения |
| **УСТАНОВКА-PWA-iPhone.txt** | Пошаговая инструкция установки на iPhone (максимально подробно) |

Все версии полностью равноценны: одни и те же **100 языков и 1163 уровня**, прогресс хранится локально в каждой версии отдельно.

### Windows

1. Распакуй `CodeQuest-Desktop-exe.zip` в любую папку (например, `C:\Games\CodeQuest`).
2. Запусти **`CodeQuest-win_x64.exe`** — откроется окно приложения, как у игр.

> ⚠️ Windows SmartScreen может предупредить о неизвестном издателе (приложение без цифровой подписи). Нажми **«Подробнее» → «Выполнить в любом случае»** — это нормально для самодельных программ.

**Требования:** Windows 10/11 (движок WebView2 предустановлен в системе автоматически). Если exe вдруг не запустился — используй портативную версию, она работает всегда.

### macOS и Linux

- **Вариант 1:** в exe-архиве лежат и другие бинарники: `CodeQuest-mac_universal`, `CodeQuest-linux_x64` и т.д.
  - macOS: правый клик по файлу → «Открыть» (обход Gatekeeper).
  - Linux: нужен пакет `libwebkit2gtk-4.1-0` (`sudo apt install libwebkit2gtk-4.1-0`), затем запусти бинарник.
- **Вариант 2:** скачай `CodeQuest-macOS.zip` — там только Mac-версии (`mac_universal` подходит для любого Mac).

### Портативная версия (100% гарантия запуска)

1. Распакуй `CodeQuest-Portable-HTML.zip`.
2. Двойной клик по **`index.html`** — приложение откроется в браузере.
3. Ещё лучше: запусти **`Запуск-в-браузере.bat`** — откроется отдельное окно без адресной строки, неотличимое от программы.

## 🤖 Android (APK)

1. Скачай **`CodeQuest-Android.apk`** и открой его на телефоне.
2. Android спросит разрешение «Устанавливать из этого источника» — разреши.
3. Готово: иконка ⚡ CodeQuest в меню приложений, работает полностью офлайн.

> Если Play Защита предупреждает о неизвестном приложении — это нормально для APK вне магазина: приложение не собирало и не собирает данные. Работает на Android 7.0+ (API 24).

## 📱 iPhone и Android (PWA)

На iPhone нельзя «просто открыть файл» как APK на Android — Apple требует, чтобы приложение пришло с сайта по защищённой ссылке (https). Поэтому приложение ставится как **PWA**: один раз размещаешь его на бесплатном хостинге — и устанавливаешь как настоящее приложение с иконкой на рабочем столе.

### Кратчайший путь (3 шага)

1. **Размести приложение в интернете:** зайди на `app.netlify.com/drop` (бесплатно, нужна регистрация) и перетащи туда файл `CodeQuest-PWA-site.zip`. Через минуту получишь адрес вида `https://твоё-имя.netlify.app`.
2. **Открой этот адрес на iPhone в Safari** (именно Safari, не Chrome — ограничение Apple) и дождись полной загрузки главного экрана.
3. **Нажми «Поделиться»** (квадратик со стрелкой вверх) → пролистай меню вниз → **«На экран “Домой”»** → **«Добавить»**.

Готово: иконка ⚡ CodeQuest на рабочем столе, открывается в полный экран, после первого запуска работает **без интернета**.

> 📖 Каждый клик с картинками и все альтернативные пути (GitHub Pages, установка прямо с iPhone, проверка офлайна) — в файле **`УСТАНОВКА-PWA-iPhone.txt`**.

### Android без APK

Проще простого: открой тот же размещённый сайт в Chrome → меню **«⋯»** → **«Установить приложение»**.

> Для публикации в App Store нужен Xcode и аккаунт разработчика Apple ($99/год) — полный Xcode-проект готов в `CodeQuest-iOS.zip`. PWA внешне и по ощущениям — то же самое приложение, но бесплатно и за 3 минуты.

## 💾 Прогресс и бэкап

- Прогресс хранится **локально на устройстве** (автоматически, после каждого действия).
- **Настройки → Экспортировать прогресс** — сохранит файл `codequest-progress.json`. Делай бэкап перед переустановкой системы и перед переходом на другое устройство.
- **Настройки → Импортировать из файла** — восстановит всё: уровни, XP, ачивки, заметки, серию дней.

При обновлении CodeQuest на новую версию прогресс не теряется — он лежит отдельно от файлов приложения. Но бэкап перед обновлением всегда полезен.

## 🔧 Как это устроено

- Приложение — это чистые **HTML + JavaScript** без фреймворков и внешних серверов: один `index.html`, стили, скрипты и файлы курсов.
- Весь прогресс — в **localStorage** браузера/приложения. Ничего не уходит в сеть.
- В десктоп-версии (Neutralino) HTML упакован в `resources.neu` и работает в системном движке: WebView2 на Windows, WKWebView на macOS, WebKitGTK на Linux.
- В Android-версии тот же HTML лежит в assets APK и открывается в системном WebView.
- В PWA-версии сервис-воркер (`sw.js`) при первом открытии скачивает все файлы в кэш — после этого интернет не нужен вовсе.
- Проверка кода: исполняемые языки (Python, JavaScript, HTML/CSS, Brainfuck) запускаются по-настоящему; остальные проверяются анализом структуры кода + квизами и «предскажи вывод».
- Режим слабого ПК: отключает анимации/конфетти, кэширует подсветку кода, режет перерисовки списков. Включается в Настройках или сам на слабом железе.

## ❓ Частые вопросы

**Задание не принимает моё решение, хотя кажется верным.**
Проверь точность: текст вывода, регистр. Пробелы в конце строк игнорируются, но регистр важен. Открой подсказки 🧠 — они не портят XP.

**Я нажал «Показать решение». Это плохо?**
Нет. Разбери решение и введи его в редактор сам — так запоминается.

**Куда пропал прогресс?**
Прогресс привязан к профилю на этом устройстве. После переноса на другой ПК/телефон — «Настройки → Импортировать из файла» (файл экспорта сними со старого устройства заранее).

**Работает ли приложение без интернета?**
Да, полностью. Десктоп, APK и портативная версии никогда не требовали сеть; PWA после первой загрузки тоже. Только первый запуск PWA должен быть с интернетом.

**Компьютер слабый, приложение тормозит?**
Настройки → «🪶 Режим слабого ПК» → включить. На машинах с 1–2 ядрами включается автоматически.

**Хочу сбросить язык и пройти заново.**
Карта языка → кнопка «♻️ Сбросить язык».

**Как поставить на iPhone, если ничего не понял?**
Открой файл **`УСТАНОВКА-PWA-iPhone.txt`** — там расписан каждый клик, включая регистрацию на хостинге и установку прямо с телефона без компьютера.

**Будут ли новые языки и уровни?**
Библиотека курсов расширяемая: файлы лежат в `content/`, каждый — самостоятельный курс с уровнями и шпаргалками.
